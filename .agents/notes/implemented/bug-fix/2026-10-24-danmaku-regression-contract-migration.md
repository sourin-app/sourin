# Agent Note: 弹幕拆分后的回归契约迁移与判据修复

Status: implemented

## Problem

第 12 项要求「设置弹窗聚焦显示、过滤等高频设置；来源选择移入高级设置」，并将搜索与选集移入独立搜索页，将请求状态与服务端返回详情放入该页可展开诊断区。旧测试仍要求来源页直接操作、设置内搜索自动提交和旧位置的加载圈，混淆了真实回归与被新需求取代的契约。来源缺省配置、主动关闭、重复集号及页面卸载后的草稿生命周期也需要独立验证。

本笔记补充而不取代 [设置滚动边界与搜索职责拆分](2026-10-23-danmaku-settings-search-boundary.md) 与 [来源默认值和冲突选择](2026-10-24-danmaku-feeds-defaults-and-conflicts.md)：前者记录拆分架构，后者记录来源与草稿修复；本篇记录回归契约迁移、加载反馈取舍和判据脆弱性。

## Decision

来源开关位于高级设置；来源页签保留导航��与只读状态摘要，不恢复重复表单，也不变成废页。旧搜索入口只调用 onOpenSearch，不自动调用 onSearch。独立页承载搜索、选择、预览与确认，网络及绑定状态仍由播放器提供。

诊断区承载请求状态、错误与服务端返回详情。401/403 文案指向 onReload 和 onOpenLocal 两条真实回调入口，不复活已经摘掉的凭证输入入口。文案提取器从独立页读取，并以控件语义边界而非固定缩进截取，避免插值字符串被单引号扫描提前截断。「混跑才红」不等于环境问题，应先检查固定缩进、固定字符窗口和固定行号等脆弱判据。

来源偏好使用 danmaku.feeds.enabled。缺省键值 null 表示首次使用，启用全部四个受支持来源；已保存的集合表示用户明确选择，不把主动关闭误判成缺省。切换通过 UiPrefs.set 和 flush 走真实持久化路径，本片源自带保持启用。

重复集号且 episodeId 不同的候选必须��显式选择；冲突未解除、计划为空、结果过期或请求在途时禁用确认。确认仍交给播放器，不在页面复制绑定实现。

搜索草稿由播放器 State 持有纯 Dart 对象，保存关键词、选择 ID 和预览状态。页面卸载后重新挂载可恢复，同一播放器会话内有效；不使用 static，不持有 BuildContext，也不写入偏好文件。

独立搜索页保留 s.searchLoading || b.loading 驱动的整行 LinearProgressIndicator。旧设置内两处搜索 spinner 已随信息架构迁移移除，库存契约迁为 dialog 两处加 settings 一处；保留 AppInlineSpinner、显式 color、禁止 CircularProgressIndicator 三条不变量、阳性对照和剥注释器自检，另守护独立页在途反馈。

## Alternatives considered

- 为满足旧库存数量，在独立搜索页增加行内 spinner：未采用。现有整行进度条已经表达双渠道在途状态，额外小圈重复反馈，且把旧测试库存误当产品需求。
- 将来源开关和搜索表单恢复到来源页：未采用。直接违反第 12 项，重新形成双入口渲染和状态漂移。
- 保留旧单引号链提取器或固定缩进边界：未采用。诊断文案包含回调条件插值，单引号链会截断；固定缩进仅是排版，不是契约。
- 默认仅启用本片源自带：未采用。与默认全开要求冲突；启用渠道不等于伪造该渠道数据，聚合仍按真实可用数据过滤。
- 重复集号静默取第一条：未��采用。用户可能绑定到另一版本，提示文字不能替代显式选择。
- static 草稿或 UiPrefs 落盘：未采用。前者跨播放器串味并污染测试，后者把会话临时输入变成持久设置。播放器 State 的生命周期与返回恢复要求一致。

## Consequences

旧位置断言按 B 类迁移到新职责位置，同时保留来源合并、持久化、像素对比度、玻璃层点击、封面降级、可编辑关键词、预览确认和过期禁用等原有实质��覆盖。来源默认值、持久化、冲突和草稿问题按 A 类修复，不逆转信息架构。

本范围 11 文件串行验证为 107 项通过、退出码 0，日志位于 .probe/regress-danmaku-after.log。Lead 冻结后最终 19 文件验证为 275 项通过、退出码 0，日志位于 .probe/lead-r9-final2.log；后者为 Lead 报告，不冒称本代理独立执行。原提取器固定缩进导致的三红是真实判据缺陷，不归为环境噪声。

故障注入仅在 .probe 下隔离副本执行，不改动已冻结的主工作区 lib/ 与 test/。注入覆盖来源默认全开、重复集号禁用确认和搜索页在途加载反馈；真实结果与退出码记录于 .probe/regress-danmaku-inject.log。
