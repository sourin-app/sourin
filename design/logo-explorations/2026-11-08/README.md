# 源影标识候选

2026-11-08。独立绘制的四款矢量方案，供选择；均未接入正式应用图标。

| 方案 | 方向 | 推荐使用场景 |
|---|---|---|
| 01 源环 | 开放圆环与播放键，多源汇聚 | 主推荐，与当前蓝色 Miuix 外观一致 |
| 02 叠映 | 层叠片库与播放留白 | 偏轻快的桌面应用 |
| 03 流光 | 弧线组成 S | 偏品牌化、强调流动 |
| 04 映窗 | 银幕和微弧底线 | 偏安静的影院工具 |

`overview.png` 是对比图，含深色、单色和小尺寸样式。每款提供透明背景 SVG、单色 SVG 和 512px PNG。选择后再完善平台圆角、安全区与 ICO/自适应图标，现阶段不覆盖正式资产。

使用 Node.js 和 sharp 执行 `node render.cjs` 可重建预览；中文预览文字使用 Microsoft YaHei，标识本身不依赖字体。
