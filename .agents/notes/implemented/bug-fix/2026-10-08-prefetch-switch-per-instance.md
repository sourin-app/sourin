# Agent Note: 流代理的预取开关按实例读，不按进程全局

Status: implemented

## Problem

`SOURIN_PREFETCH_DISABLE` 改前是每次请求现读全局环境变量。并发跑的测试会互相干扰：
一个测试改了环境变量，另一个测试的行为跟着变，红/绿取决于执行顺序。

这不是测试写法问题 —— 全局可变状态在真实并发请求下同样会被别的调用点改写。

## Decision

该开关在**构造** `StreamProxy` 时读一次并存进实例字段。

## Alternatives considered

- **让测试串行执行来规避干扰** —— 它最强的论据是零代码改动：不碰产品行为，
  只改测试调度。否决理由：它把并发安全问题转成测试调度问题，产品里的全局可变状态
  一点没动；而且串行化会掩盖同类缺陷、拖慢整批测试。

## Consequences

- **收益**：实例级状态不会被别的线程或测试改写，并发测试互不干扰，
  预取行为在实例生命周期内稳定。
- **代价与已知上限**：运行期不能动态切换预取 —— 要改就得重建实例。
- **重访条件**：不再有并发测试，且确实需要运行期动态切换预取。那时应换成
  **显式配置项**，而不是回到读环境变量。
