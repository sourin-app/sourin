# Agent Note: 钉住「中文字宽恒为 12.000/字」—— 一条防结论过期的门禁

Status: implemented

## Problem

CS-1 证据 README 与 `docs/AGENTS.md` 里写着一条我们量化出来的事实：

```text
flutter_tester 的中文宽度是固定 12.000 px/字，对所有字族相同
⇒ loadRealFonts 加载的 msyh.ttc 只让**字形**变成真的，**字宽**仍然是假的
```

这条事实支撑着一个结论：

```text
截图能证明「文字是什么」，不能证明「文字排出来多宽」
```

**问题**：如果将来 Flutter 版本升级修了这个行为（某个族真的生效、宽度不再相同），
那条结论就**过期了** —— 而没有任何东西会告诉你。文档里写着一个曾经正确的数，
比没有文档更危险。

## Decision

新增 `test/zz_t66_cs1_cjk_advance_gate_test.dart`，用 5 个族 + `null` 钉住这条事实。

```text
★★★ 五个字族的中文宽度必须**完全相同**（= 12.000/字 × 字数）
★★  每字必须 == 12.000（只证明"彼此相同"不够，还要钉住数值）
★   阳性对照：字号 12→24 宽度必须约 2 倍（证明 TextPainter 真在量）
☆   诊断：拉丁字母是否也等宽（不判红，用于定位根因）
```

### 它红了意味着什么（写进了失败信息）

```text
不是"代码坏了"，而是：
  「flutter_tester 的中文字宽不再是等宽，
    docs/notes/evidence/round-66-cs1/README.md 里「字体」节
    与 docs/AGENTS.md 的「截图里的文字全是方块」那条
    都写着「字宽恒为 12.000/字，与字族无关」—— 这个结论需要重新评估」
```

### 顺带查清的一个根因细节

```text
[LATIN] ii   = 6.39      ← 2 字，3.20/字
[LATIN] WWWW = 48.84     ← 4 字，12.21/字
[LATIN] 中文 = 48.00     ← 2 字，24.00/字 = 12.00/字
```

**拉丁字母走真实度量（比例字宽），只有中文落到固定 12.000**
⇒ flutter_tester **有真实字体**，是**中文字形缺失**才回退到固定度量。

这比 AGENTS.md 原来说的「默认字体是 Ahem」更准确：加载了也修不好的是**字宽**，不是字形。

## Alternatives considered

- **不写门禁，只在文档里写清楚** —— 否决理由：
  文档不会自己变红。这条结论一旦过期，下一个人会**基于过期事实**做判断
  （例如"反正是等宽，那我的字宽推演是准的"）。

- **用 `Note-Skip` 跳过决策笔记** —— 否决理由：
  这不是纯文档改动，它新增了一条**会变红的门禁**（有行为影响）。
  而且"为什么这条门禁的作用是防结论过期而不是防缺陷"这个意图，
  不写下来没人知道 —— 下一个人看到一条红了的门禁会去改代码。

- **只断言"五个族相同"，不断言"等于 12.000"** —— 否决理由：
  若某天全世界的字族都变成 10.0，前者仍然绿（大家一样），
  但文档里「12.000」这个数就错了。⇒ 两者都要钉。

## Consequences

### 收益

```text
· 文档里那个数有了机械守卫：Flutter 改了行为，这条会红并指向该更新的文档
· 根因（中文字形缺失 → 固定度量）被记录，不再只是"默认字体是 Ahem"这个笼统说法
· 顺带证明了 CS-1 证据图的布局结论稳固（见下）
```

### 代价

```text
· kTesterCjkAdvance = 12.0 是个**硬编码常量**，改它之前必须跑一遍看真实读数
· 这条门禁**只对中文成立**：拉丁字母是比例字宽，不能拿它推拉丁文本
```

## 回答：CS-1 两张证据图的布局结论还成立吗

**成立，且富余远超误差**（用读数，不是判断）：

```text
文案 37 字 / 宽 413.69 / 每字 11.181（widget 层，含方向说明的完整状态行）

缩放   可用宽   状态行    富余         可容忍字宽误差
100%   1888    422.9    1465.1(346%)   346%
125%   1504    422.9    1081.1(256%)   256%
150%   1248    422.9     825.1(195%)   195%
175%   1065    422.9     642.1(152%)   152%
```

⇒ 即使真机雅黑的字宽比等宽 12.000 **宽 1.5 倍**（极夸张的估计），
175% 缩放下状态行仍不会折行。**结论稳固。**
