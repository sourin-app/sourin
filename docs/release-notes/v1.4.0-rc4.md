### 修复

- 健康检测页的进度条现在会实时走动，不再一直停在「0 / 26」；跑完或手动停止后，那一行也会立刻消失。
- 中文界面下读屏朗读弹窗关闭提示时，现在读的是中文，不再念英文。
- 滚动区域的设置重新生效：此前有一次改动实际没有起作用，部分设备上内容区可能整片空白。
- 弹幕不再重复发送：此前网络超时会被误判成数据解不开，导致同一条弹幕发两遍，或者加载时白等十几秒。
- 重试时继续沿用每个源各自的代理与请求标识设置，此前重试会把代理丢掉。
- 直播源的可用状态改为按有效期判断，过期的源会重新检查；此前它们永远不再重新检查，每次启动都要把所有源重查一遍。
- 播放时快速来回切换进度时偶发的闪退已经消除。

### 改进

- 界面滚动到底或回顶时的手感更稳，边缘内容不再被生硬裁掉。
