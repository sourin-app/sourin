## 一、这条要的是什么（先划清边界，避免做成换肤）

```text
❌ 不是：换颜色、换圆角、换字体  ← 那是现有 9 套配色主题做的事
✅ 是：换**页面骨架**——导航位置、内容区组织方式、信息密度
```

⇒ 判据：三套骨架在**同一页面上，控件位置不同**。
  如果只是颜色不同，就不算完成。

## 二、现状（Lead 已核实）

```text
lib/shell.dart
  · enum AppTab 有 6 个值：home / live / follow / search / cached / settings
  · 底部导航栏 _BottomBar（玻璃胶囊 + 滑动药丸）
  · _pageFor 的 switch 按 tab 返回页面
  · 页面之间用 IndexedStack 保活

⇒ 骨架切换的**天然挂载点**就是 _BottomBar + 页面容器这两处。
   页面内容（各 _page）不需要改——只改"怎么摆"。
```

## 三、三套骨架定义

### 骨架 1 · 底栏式（现状，保留为默认）
```text
┌─────────────────────────────┐
│                             │
│         内容区              │
│                             │
│                             │
├─────────────────────────────┤
│ 发现 直播 追更 搜索 缓存 设置 │  ← 底部胶囊导航
└─────────────────────────────┘
```
· 特点：内容区最大化，适合触屏/遥控器
· 现状已实现，**零改动**，作为基准

### 骨架 2 · 侧栏式
```text
┌──────┬──────────────────────┐
│ 发现 │                      │
│ 直播 │      内容区          │
│ 追更 │                      │
│ 搜索 │                      │
│ 缓存 │                      │
│      │                      │
│ 设置 │                      │
└──────┴──────────────────────┘
   ↑ 左侧竖栏，可折叠（仅图标 / 图标+文字）
```
· 特点：桌面宽屏利用率高，导航常驻可见
· 实现要点：
```text
  · 宽度阈值：>= 900px 才展开成图标+文字，否则只显示图标（64px）
  · 折叠状态要落盘（UiPrefs）
  · 底部导航栏完全移除（不是隐藏）
```

### 骨架 3 · 顶栏 + 命令面板
```text
┌─────────────────────────────┐
│ 源影    [搜索框]        ⚙  │  ← 顶栏，设置是齿轮
├─────────────────────────────┤
│                             │
│         内容区              │
│                             │
└─────────────────────────────┘
   ↑ 无固定导航；按 Ctrl+K 或点搜索框弹命令面板切页
```
· 特点：沉浸、内容最大化，适合"看电影为主"的场景
· 实现要点：
```text
  · 顶栏只留 3 个元素：logo / 搜索框 / 设置齿轮
  · 切页走命令面板（复用现有搜索页？不——要独立一个轻量浮层）
  · ⚠️ 必须保留一条**不依赖快捷键**的切页路径（触屏用户没有 Ctrl+K）
```

## 四、实现方式（关键设计决定）

```text
抽一个 ShellLayout 抽象：
```
```dart
abstract class ShellLayout {
  Widget build({
    required AppTab current,
    required ValueChanged<AppTab> onSelect,
    required Widget body,        // 内容区（各 _page 已渲染好的）
    required List<AppTab> tabs,
  });
}
```
```text
三个实现：
  BottomBarShellLayout   ← 骨架 1（把现有 _BottomBar 搬进去）
  SideRailShellLayout    ← 骨架 2
  TopBarShellLayout      ← 骨架 3

⇒ ShellPage 只负责：算出 body，然后 layout.build(...)
  这样切骨架**不动页面代码**，也不动 IndexedStack 保活逻辑。
```

## 五、与现有主题的关系

```text
布局骨架 与 配色主题 是**正交**的两个维度：
  配色：9 套（theme_pack.dart 管）
  骨架：3 套（本任务新增）
⇒ 任意组合 = 27 种外观。

存放：UiPrefs 加一个 key（如 shell.layout），默认 bottomBar。
⚠️ 不放进 ThemePack —— 那是配色，塞进去会让导入/导出的主题文件携带布局，
   用户导入别人的配色主题时不该被改布局。
```

## 六、验收判据（Owner 亲自审）

```text

3. 切换骨架后**当前页不丢失**（不能重置到首页）
4. 骨架选择要落盘，重启后保持
5. 三套都要过：现有全部测试 + 真机截图
```
